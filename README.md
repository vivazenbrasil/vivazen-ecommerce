# VivaZen - Plataforma de E-commerce

Este documento apresenta a plataforma de e-commerce da **VivaZen**, uma solução web desenvolvida para comercializar produtos naturais com foco em saúde e bem-estar. O projeto foi concebido e implementado utilizando as melhores práticas de desenvolvimento e tecnologias modernas, visando oferecer uma experiência de usuário otimizada e um sistema robusto.

## Visão Geral da VivaZen

A VivaZen é uma marca comprometida em reconectar indivíduos com o poder da natureza, oferecendo produtos de alta qualidade que promovem equilíbrio, saúde e bem-estar. Nossa seleção de produtos é pautada por critérios rigorosos de pureza, eficácia e sustentabilidade, refletindo nosso compromisso com a qualidade de vida dos nossos clientes e o respeito ao meio ambiente.

## Funcionalidades da Plataforma

A plataforma de e-commerce VivaZen foi cuidadosamente projetada para proporcionar uma jornada de compra intuitiva e informativa, destacando os atributos e benefícios de nossos produtos. As principais funcionalidades incluem:

*   **Seção Principal (Hero Section):** Apresentação visual impactante do lançamento mais recente e da filosofia da VivaZen, convidando o usuário a explorar o catálogo de produtos.
*   **Destaque de Produtos:** Áreas dedicadas à exposição dos produtos, com ênfase em seus benefícios, ingredientes 100% naturais e embalagens sustentáveis.
*   **Informações Nutricionais Detalhadas:** Uma seção interativa que permite aos usuários visualizar a tabela nutricional dos produtos. Esta funcionalidade inclui um sistema de lupa para ampliar a visualização da tabela e gavetas expansíveis com descrições detalhadas dos nutrientes, como L-Triptofano, L-Teanina, Magnésio, Vitaminas B3 e D3, e Inositol.
*   **Seção "Sobre Nós":** Uma página dedicada a compartilhar a história, os valores e a missão da VivaZen, fortalecendo a conexão e a confiança com a marca.
*   **Navegação Otimizada:** Um cabeçalho claro e funcional, com links diretos para as principais seções do site, facilitando a exploração do conteúdo.
*   **Canais de Contato:** Um rodapé abrangente que oferece informações de contato essenciais, incluindo e-mail e WhatsApp, para suporte e comunicação eficazes.
*   **Design Responsivo:** A interface do usuário é totalmente adaptável a diversos dispositivos e tamanhos de tela, garantindo uma experiência de navegação consistente e agradável em desktops, tablets e smartphones.

## Tecnologias Empregadas

O desenvolvimento desta plataforma utilizou um conjunto de tecnologias de ponta, selecionadas para assegurar alta performance, escalabilidade, manutenibilidade e uma excelente experiência de usuário:

- **[Next.js](https://nextjs.org/)** (v16.x) - Framework React para desenvolvimento de aplicações web de alto desempenho, com recursos de renderização híbrida (Server-Side Rendering e Static Site Generation) e otimização de rotas.
- **[React](https://react.dev/)** (v19.x) - Biblioteca JavaScript fundamental para a construção de interfaces de usuário dinâmicas e reativas.
- **[Tailwind CSS](https://tailwindcss.com/)** (v4.x) - Um framework CSS utilitário que agiliza o processo de estilização, permitindo a criação de designs personalizados e responsivos com foco em performance e modularidade.
- **[TypeScript](https://www.typescriptlang.org/)** (v5.x) - Um superset do JavaScript que adiciona tipagem estática ao código, elevando a robustez, a detecção de erros em tempo de desenvolvimento e a produtividade da equipe.
- **[Lucide React](https://lucide.dev/)** - Uma biblioteca de ícones moderna e altamente personalizável, integrada para enriquecer a interface do usuário com elementos visuais claros e consistentes.
 - **Next/font:** Recurso nativo do Next.js para otimização de fontes, garantindo carregamento eficiente, evitando o Cumulative Layout Shift (CLS) e melhorando a performance geral. As fontes utilizadas são **Geist** (da Vercel) e **Jost**.

## Informações Técnicas para Desenvolvedores (Opcional)

Esta seção é destinada a desenvolvedores que desejam configurar ou contribuir com o projeto.

### Pré-requisitos de Desenvolvimento

Para configurar o ambiente de desenvolvimento, certifique-se de ter as seguintes ferramentas instaladas:

*   **Node.js:** Versão 20.x ou superior é recomendada, devido à utilização de `@types/node: ^20`.
*   **Gerenciador de Pacotes:** Utilize `npm`, `Yarn`, `pnpm` ou `Bun` de sua preferência.
